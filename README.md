# Welcome to notes-app-rn

This is a simple notes app created using React Native + Expo. It allows you to create your notes and delete.

# Features

1. Create notes
3. Delete notes
4. Add title and description of note

# Tech Stack
1. React Native
2. Expo
3. Nativewind
4. TypeScript

# Upcoming features

1. Enhanced UI
2. Support edit Notes
3. Storing todos into Database
4. Real time sync

# Steps to install

```bash
# Clone respository
git clone https://github.com/swapnasahoo/notes-app-rn.git

# Move to project folder
cd notes-app-rn

# Install dependecies
npm install

# Run development server
npx expo start --clear
```
